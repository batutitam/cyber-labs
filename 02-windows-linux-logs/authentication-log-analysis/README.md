# Анализ Linux Authentication Logs и расследование подозрительной SSH-активности

## 1. Обзор лабораторной работы

Лабораторная работа посвящена анализу Linux Authentication Logs и выявлению подозрительных событий, связанных с SSH-аутентификацией.

В ходе исследования рассматриваются три синтетических набора журналов, содержащих нормальную активность, подозрительные попытки входа и смешанные события аутентификации.

Основное внимание уделяется анализу событий, выявлению закономерностей, сопоставлению записей и формированию обоснованных выводов на основании имеющихся данных.

## 2. Цели исследования

- Научиться анализировать успешные и неудачные попытки SSH-аутентификации.
- Определять IP-адреса источников подключений и атакуемые учётные записи.
- Выявлять признаки Password Guessing и Username Enumeration.
- Анализировать частоту и последовательность событий аутентификации.
- Сопоставлять события входа с записями sudo и завершения сессий.
- Разделять подтверждённые факты, предположения и гипотезы.
- Формировать выводы на основании доступных доказательств.

## 3. Среда и инструменты

**Операционная система:** Ubuntu в WSL2.

**Используемые инструменты:**
- Bash
- grep
- awk
- sort
- uniq
- cut
- wc

**Источник данных:** синтетические Linux Authentication Logs.

## 4. Описание наборов данных

Для исследования используются три файла:

| Файл | Описание |
|---|---|
| `auth-normal.log` | Нормальная активность аутентификации, успешные входы и отдельная неудачная попытка |
| `auth-suspicious.log` | Множественные неудачные попытки входа, использование разных имён пользователей и последующая успешная аутентификация |
| `auth-mixed.log` | Смешанные события: SSH-входы, неудачная аутентификация, sudo и события пользовательских сессий |

Все журналы являются синтетическими и созданы исключительно для учебных целей.

В наборах используются частные IP-адреса и адреса из TEST-NET — специальных диапазонов, предназначенных для документации и примеров. Данные не представляют реальных внешних источников атак.

## 5. Методология исследования

Анализ выполнялся последовательно:

1. Выделение успешных и неудачных событий аутентификации.
2. Определение IP-адресов источников и имён пользователей.
3. Подсчёт количества попыток входа по каждому IP-адресу.
4. Определение уникальных IP-адресов.
5. Сопоставление неудачных и успешных попыток входа.
6. Анализ временных интервалов и последовательности событий.
7. Изучение связанных записей sudo и событий пользовательских сессий.
8. Формирование выводов и определение ограничений исследования.

## 6. Основные результаты

В ходе исследования выявлены различные сценарии аутентификации:

- В `auth-normal.log` обнаружены успешные входы и отдельная неудачная попытка, после которой последовала успешная аутентификация.
- В `auth-suspicious.log` обнаружены многочисленные неудачные попытки входа с использованием разных имён пользователей.
- В `auth-suspicious.log` также выявлена успешная аутентификация после серии неудачных попыток с того же IP-адреса.
- В `auth-mixed.log` обнаружены попытки входа с несуществующими именами пользователей, события sudo и записи о пользовательских сессиях.

Выявленные закономерности могут указывать на подозрительную активность, однако сами по себе не доказывают компрометацию учётной записи.

Подробные результаты и разбор событий представлены в [Investigation Summary](reports/investigation-summary.md).

## 7. Ограничения исследования

- Используются синтетические журналы, а не реальные события производственной системы.
- Доступные записи содержат ограниченный контекст пользовательских сессий и процессов.
- Совпадение IP-адреса или близость событий по времени сами по себе не доказывают причинно-следственную связь.
- Для подтверждения компрометации могут потребоваться дополнительные данные: audit logs, process information и сведения о сетевых подключениях.

## 8. Заключение

Лабораторная работа демонстрирует практический подход к анализу Linux Authentication Logs с использованием инструментов командной строки.

В ходе исследования отрабатываются выявление подозрительных шаблонов аутентификации, анализ последовательности событий и оценка потенциальных угроз.

Особое внимание уделяется доказательному подходу: выводы должны соответствовать имеющимся данным и не выходить за пределы подтверждённых фактов.
