# Linux System Log Analysis — WSL2

## 1. Investigation Objective

Цель исследования — освоить анализ системных журналов Linux и научиться выявлять события, которые могут указывать на ошибки конфигурации, сбои служб или потенциальные проблемы безопасности.

В рамках лабораторной работы исследовались журналы Ubuntu, работающей в WSL2, с использованием `journalctl` и дополнительных системных инструментов.

Основные задачи:
- изучить системные события и сообщения служб;
- выявить повторяющиеся ошибки и предупреждения;
- проверить контекст подозрительных сообщений;
- отличить особенности среды WSL2 от потенциальных признаков инцидента безопасности;
- сформулировать выводы на основании доступных технических свидетельств.

## 2. Scope

**Environment:** Ubuntu on WSL2  
**Analysis type:** Linux System Log Analysis  
**Tools:** `journalctl`, `systemctl`, `stat`, `file`, `findmnt`, `namei`, `ps`

Исследование ограничено системными журналами и конфигурацией собственной Ubuntu в WSL2. Оно не является полным аудитом безопасности Windows или Linux и не охватывает всю сетевую инфраструктуру.

## 3. Methodology

Для анализа использовались следующие команды:

| Command | Purpose |
|---|---|
| `journalctl -n 20 --no-pager` | Просмотр последних 20 записей журнала |
| `journalctl -u wsl-pro.service --no-pager` | Фильтрация событий конкретной systemd-службы |
| `journalctl -p warning --no-pager -n 20` | Просмотр предупреждений и более критичных сообщений |
| `systemctl status` | Проверка состояния системных служб |
| `stat`, `ls -l`, `file` | Исследование файлов и их атрибутов |
| `findmnt` | Определение файловой системы и параметров монтирования |
| `namei -l` | Проверка компонентов пути и прав доступа |

При оценке событий учитывались источник сообщения, severity, повторяемость, временной контекст и дополнительные технические свидетельства.

## 4. Findings

### 4.1 WSL Pro Service

В журнале обнаружены повторяющиеся предупреждения `wsl-pro-service`.

Наблюдения:
- служба не могла подключиться к Windows Agent;
- отсутствовал файл `.address`;
- возникали ошибки конфигурации Landscape;
- в сообщениях указывалось, что для настройки Landscape необходимы account name и computer title;
- служба предпринимала повторные попытки запуска и завершалась.

**Assessment:** наблюдения указывают на проблему настройки интеграции Ubuntu Pro / Landscape с Windows Agent. В исследованных сообщениях нет самостоятельных доказательств вредоносной активности.

### 4.2 WSL System Generator Permission Warning

В журнале обнаружено предупреждение systemd о том, что:

`/run/systemd/system-generators/wsl-generator`

имеет признаки world-writable файла.

Дополнительная проверка показала:
- `wsl-generator` является символической ссылкой на `/init`;
- `/init` принадлежит `root`;
- `/init` имеет права `0777`;
- `/init` находится в файловой системе `rootfs`, смонтированной с параметром `ro` (read-only).

**Assessment:** systemd обнаруживает небезопасные биты разрешений и сообщает об этом. При этом файловая система доступна только для чтения, что ограничивает возможность изменения файла через эту файловую систему. Наблюдение требует внимания, но само по себе не подтверждает компрометацию системы.

### 4.3 Journal File Recovery

В журнале обнаружено сообщение о повреждении или некорректном завершении работы файла `system.journal`. systemd-journald переименовал проблемный файл и создал новый.

**Assessment:** сообщение может быть связано с некорректным завершением предыдущего сеанса или состоянием среды. Само по себе оно не доказывает вмешательство злоумышленника.

### 4.4 Other System Warnings

Также обнаружены предупреждения и ошибки, связанные с особенностями виртуализированной среды и отдельными системными компонентами:

- PCI: отсутствие доступа к PCI configuration space;
- device-mapper: предупреждение о параметре конфигурации;
- PulseAudio: предупреждение о `memfd_create()`;
- `dxg`: ошибки взаимодействия с графической подсистемой WSL;
- systemd-sysctl: отсутствие определённого kernel-параметра;
- chronyd: предупреждение о синхронизации времени в container-like environment;
- WSL networking: ошибка `getaddrinfo()`.

**Assessment:** эти сообщения могут быть связаны с особенностями WSL2, доступностью компонентов Windows и конфигурацией отдельных служб. Для подтверждения реальной проблемы потребовались бы дополнительные проверки соответствующих подсистем.

## 5. Security Assessment

В ходе исследования были обнаружены:
- повторяющиеся ошибки настройки WSL Pro / Landscape;
- предупреждение systemd о правах доступа к генератору WSL;
- сообщение о восстановлении файла системного журнала;
- предупреждения отдельных системных компонентов.

При этом в исследованных данных не обнаружено достаточных свидетельств, позволяющих подтвердить компрометацию системы или активность злоумышленника.

Важно: отсутствие таких свидетельств в проверенных журналах не означает, что вся система гарантированно безопасна. Исследование имело ограниченный scope.

## 6. Conclusion

Лабораторная работа позволила изучить практический анализ системных журналов Linux с помощью `journalctl`, фильтрацию событий по systemd-службам и severity, а также дополнительную проверку файлов, процессов и параметров файловой системы.

Основная часть обнаруженных сообщений относится к настройке и особенностям среды WSL2. Предупреждение о правах `/init` заслуживает отдельного внимания, однако read-only состояние файловой системы ограничивает практическую возможность его изменения через этот mount.

**Final assessment:** Security incident not confirmed. Обнаружены конфигурационные предупреждения и особенности работы WSL2, требующие контекстной оценки.

## 7. Recommendations

- Продолжать проверять повторяющиеся ошибки системных служб.
- При анализе предупреждений проверять не только текст сообщения, но и источник, контекст и состояние соответствующей подсистемы.
- Не изменять права системных файлов и не отключать службы без понимания последствий.
- При публикации лабораторной работы не включать необработанные системные журналы, персональные пути и другие идентифицирующие данные.
- В следующих лабораторных работах перейти к анализу authentication logs и событий входа в систему.
